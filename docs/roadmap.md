# Roadmap

## M1 — Control

- device list/selection
- manual LAN connection
- health/status refresh
- local playback control
- Spotify playback control
- battery/Wi-Fi compact status
- Bluetooth on-demand view
- TTS
- Bonjour discovery preparation

## M2 — Discovery and polish

- live Bonjour device discovery once MuPiBox-NG advertises `_mupibox._tcp`
- merge discovered/saved boxes without duplicates
- richer now-playing artwork/progress
- accessibility/Dynamic Type review
- localization baseline (German/English)
- parity screenshot/checklist process

## M3 — Safe configuration

Implement as a coordinated Android+iOS milestone:

- admin authentication/session
- Wi-Fi configuration
- Bluetooth enable/pair/connect management
- audio/device settings
- TTS language/voice settings
- selected system settings
- connection-loss/restart-required safety UX

## M4 — Advanced companion features

Possible later items, only against verified server APIs:

- local media browsing/launching
- richer MuPiHAT battery/charging diagnostics
- navigation/library administration
- update/maintenance status
- notifications/background integrations where iOS/Android allow them cleanly
