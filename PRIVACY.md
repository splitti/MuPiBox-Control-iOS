# Privacy

MuPiBox Control is designed as a local-network companion for MuPiBox.

M1 stores the configured MuPiBox names, local host/IP addresses, ports and the selected box on the device. It communicates directly with the selected MuPiBox over the local network.

The app does not need cloud analytics, advertising identifiers or location data for its core control functions. Bonjour/local-network access is used only to find and communicate with MuPiBox devices on the user's LAN.

Future features that add external services, telemetry or account data must update this document and the App Store privacy declaration before release.
